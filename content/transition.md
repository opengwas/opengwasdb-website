## What's different

|  | Legacy service | New catalogue |
|---|---|---|
| Unit of data | Datasets, in batches such as `ieu-a` and `ukb-b` | Analyses, in store releases such as `OGS-00009` |
| How you get it | The OpenGWAS API, with a token | Store releases to download, and a hosted platform (both being set up) |
| Versioning | | Each store release is fixed once published |

*To be written: identifiers, genome build, which tools work with which, and why the numbers of datasets and analyses differ.*

## Legacy IDs

Legacy dataset IDs such as `ieu-a-2` are not used in the new catalogue. The [analysis tools](/tools/) will map legacy IDs to the new ones.
